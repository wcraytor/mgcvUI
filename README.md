# mgcvUI — retired, superseded by earthUI

> **This repository is feature-frozen and archived.** The mgcvUI
> application now ships **inside the earthUI package** as its GAM
> Post Processing Module.
>
> ```r
> install.packages("earthUI")   # CRAN
> earthUI::launch_mgcv()        # this application, current version
> ```
>
> All development continues at
> [wcraytor/earthUI](https://github.com/wcraytor/earthUI). This repository
> remains available for its commit history; the code here predates the
> merge and no longer receives fixes.
